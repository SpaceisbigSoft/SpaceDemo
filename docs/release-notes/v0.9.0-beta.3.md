**SpaceDemo 0.9.0 beta 3 — a test version.** Watch old Counter-Strike 1.0–1.6 demos in today's Steam CS 1.6, with the original voice.

### New in beta 3
- **CS 1.0, 1.1 and 1.2 demos (2000–2001) now play.** These use the oldest demo format (network protocol 43); SpaceDemo now reads and converts it, so every CS release from 1.0 to 1.6 is covered. (There's no voice in these: voice chat came with CS 1.3.)
- **AI voice per demo:** a new **AI voice** column in the Library (and a box on each demo's page). Settings → AI voice enhancement stays the default; ticking or unticking a demo changes only that one.
- **Old maps' texture files** (`.wad`) are also looked for in all your old-map folders, not only next to the map.
- Fixes: the Library's buttons line up; screen readers read the Radar replay's key panel correctly.

### Updating from beta 2
SpaceDemo beta 2 asks by itself (a few seconds after it starts): click **Download**, then **Restart now**. Your library and settings stay. (No bar? Settings → Updates → **Check now**.)

### New install
1. Download **SpaceDemo-Setup-0.9.0-beta.3.exe** below (Windows 10/11, 64-bit).
2. Windows SmartScreen may say *"Windows protected your PC"*: the installer isn't signed. Click **More info → Run anyway**.
3. You need **Steam** with **Counter-Strike** installed, and some old `.dem` demos (loose, in folders or in zips).

How to use it: the [user guide](https://github.com/SpaceisbigSoft/SpaceDemo/blob/main/docs/USER-GUIDE.md), or the **Help** page in the app.

### Safe to use
SpaceDemo never changes your demos or the game's files, doesn't touch the running game, and starts demos through Steam with `-insecure` (VAC off for that session only).
